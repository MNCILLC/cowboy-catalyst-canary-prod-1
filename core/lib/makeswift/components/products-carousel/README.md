# Products Carousel

In **Catalog → Products Carousel**, set **Product collection** to **Category**
and choose a **Product category**. The searchable picker includes nested
categories, with parent names shown in their labels. It uses the current
storefront channel and locale.

**Max products** limits the total number of displayed products, including
**Additional products**. It defaults to 12 and accepts whole numbers from 1 to 50.
The existing saved `limit` setting is preserved. Collection products come first;
additional products appear afterward when there is room under the maximum.
The maximum also applies when using **None (static only)**.

The category setting is only used for the Category collection. Other collection
options remain available. Category products use BigCommerce's category product
ordering and retain customer pricing, preferred currency, and existing product
filtering.
